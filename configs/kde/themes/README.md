# Downloaded KDE Themes

Sanitized local theme assets staged from the source system.

Included Plasma desktop themes:

- `Layan`
- `Orchis-dark`
- `Sweet`
- `Sweet-Ambar-Blue`

Included look-and-feel package:

- `com.github.vinceliuice.Orchis-dark`

Included color schemes:

- `Orchis.colors`
- `OrchisDark.colors`
- `Sweet.colors`
- `SweetAmbarBlue.colors`

Included Aurorae window decorations:

- `Orchis`
- `Orchis-dark`
- `Orchis-dark_x1.5`
- `Orchis_x1.5`
- `Sweet-ambar-blue`
- `Sweet-Dark`
- `Sweet-Dark-transparent`

Included icon themes:

- No full icon theme directories are bundled. The installer uses `papirus-icon-theme` from Fedora packages instead.

Included wallpapers:

- `Orchis`

The KDE installer copies these only when the target path does not already exist.

Removed for public-release safety:

- `Tokyo Night.colors`: source metadata was not present in the file.
- `Sweet-Wallpapers`: source metadata was not present in the staged wallpaper directory.
