# Icon Themes

Large downloaded icon theme directories are intentionally not bundled in this public starter kit. Full icon packs can add hundreds of megabytes and often include generated cache files.

The installer uses Fedora packages where possible:

- `papirus-icon-theme`

Good optional icon themes to install manually:

- Candy Icons
- Reversal
- Tela Circle

Existing icon themes on the target machine are never overwritten by this kit.
