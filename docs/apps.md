## Risk tiers

Low-risk defaults are Fedora packages and user-owned dotfiles with backups.

Medium-risk items include Flatpak apps, KDE config edits, and browser policies.

High-risk items include COPRs, RPM Fusion, global npm packages, and anything that modifies system services.
